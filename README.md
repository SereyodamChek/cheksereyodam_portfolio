## 🚀 Key Features

* 🎹 **3D Interactive UI (Spline)**

  * Interactive keyboard representing skills
  * Hover effects reveal details dynamically

* ✨ **Smooth Animations**

  * GSAP & Framer Motion powered transitions
  * Scroll, hover, and reveal animations

* 🌌 **Space-Themed Design**

  * Particle effects and futuristic visuals
  * Dark aesthetic with immersive feel

* 📱 **Fully Responsive**

  * Works across desktop, tablet, and mobile

* 🧠 **Creative UX/UI**

  * Focus on storytelling and interaction
  * Designed to stand out from traditional portfolios

## 🛠️ Tech Stack

* ⚛️ **Next.js (App Router)**
* 💻 **TypeScript / React**
* 🎨 **Tailwind CSS + Shadcn UI + Aceternity UI**
* 🎬 **GSAP + Framer Motion**
* 🧩 **Spline (3D interactions)**
* 📡 **Resend (email service)**
* 🔌 **Socket.io**
* 🧠 **Zod (validation)**

## ⚙️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/cheksereyodam_portfolio.git
cd cheksereyodam_portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create `.env.local`:

```env
RESEND_API_KEY=your_resend_api_key
```

---

## ▶️ Run the Project

```bash
npm run dev
```

Open:
👉 [http://localhost:3000](http://localhost:3000)

---

## 🚀 Deployment

Deploy easily using **Vercel**:

👉 [https://vercel.com](https://vercel.com)
